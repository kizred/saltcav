# Руководство saltcav

saltcav моделирует скважинное выщелачивание соляной камеры: рост камеры при
растворении, неопределённость геологии и режима (Монте-Карло) и устойчивость
камеры с учётом ползучести соли.

## Рабочий цикл

1. **Параметры.** Откройте пример (`configs/…yaml`) или начните с «Новый». Заполните
   разделы слева. Подсказка у каждого поля — при наведении; полная справка по полю,
   на котором стоит курсор, — **F1**. Пустое поле означает значение по умолчанию
   (оно видно серым).
2. **Проверить** (Ctrl+K). Ошибки — красным в списке справа и в самом поле; щелчок по
   ошибке открывает раздел. Предупреждения (жёлтые) не мешают расчёту, но говорят, что
   результат может быть не тем, какого вы ждёте.
3. **Рассчитать** (F5) — выщелачивание по графику режима. Результат — во вкладке
   «Выщелачивание»: камера по шагам, разрез, концентрации, события.
4. **Ансамбль** (F6) — много реализаций с разбросом параметров; огибающие формы,
   P10/P50/P90, таблица реализаций. Любую реализацию можно открыть с полной историей
   или посчитать для неё геомеханику.
5. **Геомеханика** (F7) — ползучесть массива вокруг камеры после выщелачивания:
   конвергенция, запас по дилатансии, напряжения у стенки.
6. **Сохранить** (Ctrl+S) — YAML-файл; результаты — «Файл → Сохранить результаты…».

Окно и командная строка работают с одними и теми же файлами: файл, сохранённый в окне,
можно посчитать командой `saltcav run`, и наоборот.

## Симметричная и несимметричная камера

Отдельного режима нет — симметрия следует из параметров.

| Что нужно | Как задать |
| --- | --- |
| Осесимметричная камера (быстро) | Сетка → число секторов `1` |
| Систематическая асимметрия (наклон пластов, анизотропия) | секторов `12–36`; Геология → амплитуда асимметрии `a` (например 0,3) и азимут φ₀ |
| Случайная асимметрия (неоднородность породы) | секторов `12–36`; Неопределённость → σ поля ln k (например 0,3); затем «Ансамбль» |

Несогласованные сочетания (асимметрия при одном секторе, много секторов без источника
асимметрии) отмечаются предупреждением.

Геомеханика — две постановки (Геомеханика → «model»):

- **axisym** — осесимметрия по эквивалентному радиусу (площадь сечений сохраняется);
  секунды, годится для конвергенции одиночной камеры и для ансамблей;
- **3d** — полная форма R(z, φ) на тетраэдрах; минуты и 2–3 ГБ памяти; нужна, когда
  важна асимметрия: широкий пролёт кровли в одном направлении, тонкие места стенки.
  Во вкладке «Геомеханика» — разрез под любым азимутом и развёртка стенки.

## Разделы параметров

- **Сетка** — интервал глубин, число слоёв и секторов, радиус ствола.
- **Геология и прослои** — доля нерастворимых, разрыхление, плотность соли,
  асимметрия, нерастворимые прослои (ангидрит, глина) и критический вылет карниза.
- **Режим** — ступени: длительность, прямоток/противоток, расход, глубины башмаков
  закачки и отбора, уровень нерастворителя.
- **Выщелачивание** — закон растворения (k0, показатель, кровля/подошва), струя,
  численные параметры, частота сохранения шагов.
- **Неопределённость** — разбросы для ансамбля: поле ln k, длины корреляции, k0,
  отношение кровля/стенка, критический вылет, расход; разбросы отметок прослоев —
  в таблице прослоев.
- **Ансамбль** — число реализаций, seed (тот же seed — тот же результат), план
  (Монте-Карло, латинский гиперкуб, Соболь).
- **Геомеханика** — момент формы, сетка, упругость, давление пород, температура, законы
  ползучести, ступени давления в камере (рассол, газ), критерий дилатансии.
- **Устойчивость** — суррогат по ансамблю: выборка, уточнение, 3D, порог запаса.
- **Калибровка** — какие параметры подбирать по данным и их априорные границы,
  погрешности замеров, метод (MAP или MCMC).

## Устойчивость по ансамблю (суррогат)

Вкладка «Ансамбль» → «Устойчивость по ансамблю». Геомеханика считается для части
реализаций (раздел «Устойчивость»: начальная выборка, уточнение, 3D), для остальных —
гауссов процесс по признакам формы и параметрам механики. Результат — вкладка
«Устойчивость»:

- **P(запас < порога)** — вероятность потери устойчивости по ансамблю; ± — из-за
  конечного числа реализаций; «с неопределённостью суррогата» — с учётом того, что
  суррогат знает запас неточно;
- **запас на 95 % стенки** — главный показатель: минимум в одной точке у острого угла
  зависит от сетки и выводится только для справки;
- **проверка вне обучения** — насколько суррогат предсказывает расчёт; если R² < 0,5,
  разброс выхода сопоставим с погрешностью расчёта: выход почти не зависит от
  неопределённых входов;
- **что определяет запас** — какие признаки формы и параметры сильнее всего меняют
  запас;
- таблица реализаций с наименьшим запасом — любую можно посчитать полностью.

Неопределённость механики задаётся в разделе «Неопределённость»: множитель скорости
ползучести и плотность покрывающих пород.

## Калибровка по данным скважины

Вкладка «Калибровка» (F8): «Данные…» — папка с CSV (режим, рассол, сонар, прослои;
формат — `docs/data-format.md`), замечания к данным появляются сразу. «Калибровать»
подбирает параметры раздела «Калибровка» так, чтобы модель воспроизвела концентрацию
рассола и профили сонара. «Подгонка до N сут» оставляет поздние замеры для проверки
прогноза.

- **Картинка:** рассол (точки — замеры, линия — модель, полоса — 90 % по
  неопределённости параметров), профили сонара, распределения параметров;
- **таблица:** априорное, лучшая оценка (MAP), медиана и 90 % интервал (у синтетики —
  ещё и истина);
- **χ²/N** ≈ 1 — модель описывает данные в пределах погрешностей; > 2 — погрешности
  занижены или модели чего-то не хватает, интервалы тогда занижены;
- «данные почти не ограничивают» — параметр по этим данным не определить (например,
  кровля при работе под нерастворителем);
- **«Применить к параметрам»** — оценки в разделы параметров, их разброс (k0,
  кровля/стенка) — в «Неопределённость», режим и прослои — из данных. Дальше —
  ансамбль (F6) уже по откалиброванной модели.

Демо: открыть `configs/demo_calibration.yaml`, данные `data/demo/well-1` (синтетика со
скрытыми параметрами); открытый эталон — `data/open/sansmic-direct` с
`configs/benchmark_sansmic_direct.yaml`.

## Консоль Python и скрипты

«Вид → Консоль Python» (Ctrl+`) — Python прямо в окне, как макросы в ANSYS APDL.
Ctrl+Enter — выполнить; Ctrl+↑/↓ — история. Расчёт идёт в фоне, «Отмена» работает,
если скрипт вызывает `progress(доля, текст)`.

```python
res = sc.run(sc.set(cfg, leaching__k0_m_per_s=2e-5))
print(sc.table(res))
show(res)  # на вкладку «Выщелачивание»
for rate in (40, 60, 80):  # серия расчётов
    r = sc.run(sc.set(cfg, {"schedule.stages.0.rate_m3_per_h": rate}))
    print(rate, round(r.volume[-1]))
show(sc.plot(r))  # рисунок в отдельном окне
apply(sc.set(cfg, grid__nz=300))  # изменить параметры в форме
```

- `sc` — API: `load`, `save`, `get`, `set`, `run`, `ensemble`, `mechanics`,
  `stability`, `calibrate`, `data`, `sweep`, `plot`, `table`;
- `cfg` — параметры из формы на момент запуска; `show(obj)` — показать результат;
  `apply(cfg)` — загрузить в форму; `progress(доля, текст)` — полоса хода.

Путь параметра — как в YAML через точку; элементы списков — по номеру с нуля:
`schedule.stages.1.rate_m3_per_h`, `geology.layers.0.top_m`. «Файл → Выполнить
скрипт…» (Ctrl+R) выполняет файл .py в той же среде; такие же скрипты работают и без
окна: `python скрипт.py` с `import saltcav.api as sc`. Примеры — папка `examples/`.

## Просмотр результатов

- **Выщелачивание:** ползунок шагов, ▶ — воспроизведение, ← → — шаг; раскраска стенки
  (радиус, скорость растворения, недонасыщение, свойства породы); «разрез пополам»;
  разрез через ось по сектору; график по времени (щелчок — переход); журнал событий
  (двойной щелчок — переход). Файл → скриншот, анимация GIF/MP4, серия для ParaView.
- **Геомеханика:** ползунок по годам; поля слева и справа (запас по дилатансии,
  напряжения, смещения, ползучесть); масштаб смещений контура; конвергенция и запас.

## Как читать критерии устойчивости

- **Запас по дилатансии** (Ratigan): < 1 — соль разуплотняется (растёт
  проницаемость); проектное требование обычно ≥ 1,5. Сразу после снижения давления
  запас минимален, потом ползучесть разгружает стенку.
- **σ вдоль стенки − p** (МПа): напряжения вдоль стенки должны превышать давление в
  камере, иначе возможен гидроразрыв/проникновение рассола. Около нуля — стенка
  «разгружена» ползучестью до давления рассола.
- **Конвергенция:** потеря объёма камеры, %/год; под рассолом обычно доли процента в
  год, при низком давлении газа — больше.
- **Прослои** (ангидрит, глина) — отдельный материал: жёстче соли, не ползут, выше
  прочности на сжатие текут (иначе набирали бы сотни МПа). Критерии соли к ним не
  применяются (на поле запаса — серым); для них — растяжение относительно прочности
  на разрыв: > 1 — возможна трещина, карниз может обрушиться. Свойства — раздел
  «Геомеханика», таблица свойств прослоев по породе; там же флажок, выключающий прослои
  (тогда весь массив — соль).

## Командная строка

```
saltcav check  файл.yaml                 проверить параметры
saltcav run    файл.yaml --out hist.npz  выщелачивание
saltcav view   hist.npz                  просмотр по шагам
saltcav ensemble файл.yaml -n 200 --jobs 0 --plot env.png
saltcav mechanics файл.yaml --plot mech.png
saltcav surrogate файл.yaml -n 200 --plot stab.png
saltcav data   папка                     проверить данные скважины
saltcav calibrate файл.yaml --data папка --plot calib.png --write-config new.yaml
saltcav gui    [файл]                    это окно
```

## Ограничения (текущая версия)

- Параметры по умолчанию — из литературы и открытых бенчмарков (SANSMIC, WIPP, BGRa);
  до калибровки по данным месторождения результаты — оценочные.
- Связь «выщелачивание → механика» односторонняя (механика по итоговой форме).
- Прослой жёстко сцеплен с солью (без проскальзывания по контакту) — растяжение в
  прослое, вероятно, завышено; после трещины прослой в модели остаётся сплошным.
- Подробности моделей и принятых решений — `docs/decisions.md` в репозитории.
