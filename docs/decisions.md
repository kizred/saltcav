# Журнал решений

Формат: дата — решение — почему — альтернативы.

## 2026-10-24 — Свой код выщелачивания, готовая библиотека для геомеханики

- **Решение:** модель выщелачивания пишем сами (Python + Numba) на сетке R(z, φ);
  геомеханику считаем в FEniCSx, свой МКЭ не пишем.
- **Почему:** выщелачивание — научная новизна и должно быть быстрым для Монте-Карло;
  нелинейная ползучесть в 3D требует проверенного решателя и верификации.
- **Альтернативы:** свой МКЭ (долго, трудно верифицировать); MOOSE (выше порог входа);
  только коммерческие пакеты (нет контроля над моделью, используем для сверки).

## 2026-10-24 — Случайность во входных данных, а не в событиях растворения

- **Решение:** Монте-Карло по реализациям геологии и режима с коррелированными полями.
- **Почему:** при заданных условиях растворение почти детерминировано; независимые
  ячейки дают нефизичный шум.
- **Альтернативы:** вероятностный клеточный автомат с независимыми ячейками.

## 2026-10-24 — Источники данных для калибровки

- **Решение:** основа — данные компании; физическая модель для k(θ) и стратификации;
  сонар при возможности. До получения данных — открытые: SANSMIC, отчёты SPR, литература.
- **Почему:** данные компании описывают реальный объект; физмодель даёт контролируемые
  условия; открытые данные позволяют отладить код заранее.

## 2026-10-24 — Конфигурация: YAML + pydantic, единицы в именах полей

- **Решение:** строгая схема (лишние поля запрещены), единицы в имени поля
  (`rate_m3_per_h`), перевод в СИ через свойства.
- **Почему:** ошибки единиц и опечатки в конфигурации ловятся при загрузке, а не в
  середине ансамбля.

## 2026-10-24 — Геометрия: фрустумы по z, секторы по φ

- **Решение:** стенка R задаётся в узлах глубины (nz+1) и центрах nphi секторов; между
  узлами — усечённый конус. Радиальные грани между секторами в площадь растворения не входят.
- **Почему:** точно для цилиндра и конуса, второй порядок сходимости для гладких форм,
  дешёвые векторные вычисления; согласуется со слоями концентрации C(z).
- **Альтернативы:** ступенчатые цилиндры (первый порядок), level-set (дорого для ансамблей).

## 2026-10-24 — Угол ориентации стенки ψ

- **Решение:** ψ — угол между нормалью «в соль» и вертикалью вверх: 0° кровля,
  90° вертикаль, 180° подошва. Закон k(ψ) задаётся в этой системе.
- **Почему:** однозначно и не зависит от направления оси z. В литературе встречаются
  другие соглашения (например, 180° для растворения вверх) — при переносе коэффициентов
  из статей угол пересчитывать.

## 2026-10-24 — Свойства рассола: таблицы CRC, открытые вопросы

- **Решение:** плотность воды, растворимость и плотность рассола по таблицам CRC
  с интерполяцией; температурная поправка плотности рассола — множитель ρ_w(T)/ρ_w(20 °C).
- **Открыто:** вязкость рассола (нужна для чисел Ra, Sc на этапе 2) — выбрать корреляцию;
  влияние давления на плотность; сверить таблицы с лабораторными данными компании.

## 2026-10-24 — Баланс рассола: неявный перенос + перемешивание по плотности

- **Решение:** колонна слоёв по z; перенос от башмака закачки к башмаку отбора —
  неявная схема против потока; отбор Q_out = Q_in − ΔV/dt; неустойчивые по плотности
  слои мгновенно перемешиваются (изотоническая регрессия, PAV).
- **Почему:** безусловная устойчивость при крошечных начальных объёмах слоёв у скважины;
  точное сохранение соли; всплытие пресной воды при прямотоке получается само.
- **Ограничения:** первый порядок по времени; нет турбулентной диффузии между слоями
  и модели струи (часть 4 этапа 2); изменение объёма смеси при растворении не учитывается.
