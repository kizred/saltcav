# Руководство пользователя

Руководство — [`src/saltcav/gui/help/guide.md`](../src/saltcav/gui/help/guide.md): тот же
текст открывается в окне программы («Справка → Руководство», F1 — справка по полю).
Справочник всех параметров с единицами и пределами — «Справка → Справочник параметров»
(строится из модели конфигурации, поэтому всегда актуален).

## Материал слоя из библиотеки

На вкладке «Параметры» укажите корень в поле «Библиотека материалов» (относительный путь —
от каталога YAML). В разделе «Геология и прослои» столбец `material_id` содержит только породы
из `materials/`, без рабочих сред. Выберите запись или «— без материала —» и нажмите Ctrl+S:
в YAML сохраняется только ссылка выбранного слоя, свойства записи не копируются. Слой без ссылки
остаётся без выбора; неизвестный сохранённый `id` не подменяется, а отмечается ошибкой с номером
слоя.

## Рабочая среда закачки из библиотеки

На вкладке «Параметры» укажите корень в поле «Библиотека материалов и сред» (кнопка «…»),
затем в разделе «Выщелачивание» выберите среду в поле `injection_fluid_id`. Список содержит
только пригодные для закачки записи из `fluids/`; «Без привязки к библиотеке» удаляет ссылку.
Сохраните файл через Ctrl+S: в YAML записываются только `materials_library` и идентификатор
`leaching.injection_fluid_id`, свойства среды не копируются. Явно заданная
`injection_concentration_kg_m3` сохраняется и имеет приоритет над библиотечным значением.
Формат каталога описан в [materials-library.md](materials-library.md).

Пример `configs/example_saline_injection.yaml` задаёт короткий расчёт с закачкой
рассола концентрацией 120 кг/м³. Значения условные и служат для демонстрации,
для проектирования нужны проверенные данные. Запуск из корня проекта:

```bash
saltcav run configs/example_saline_injection.yaml
```
