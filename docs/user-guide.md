# Руководство пользователя

Руководство — [`src/saltcav/gui/help/guide.md`](../src/saltcav/gui/help/guide.md): тот же
текст открывается в окне программы («Справка → Руководство», F1 — справка по полю).
Справочник всех параметров с единицами и пределами — «Справка → Справочник параметров»
(строится из модели конфигурации, поэтому всегда актуален).

  примеры в [`examples/`](../examples);
