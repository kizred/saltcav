# Бенчмарк: SANSMIC

Сверка с [SANSMIC](https://github.com/sandialabs/sansmic) (Sandia, BSD-3) — ворота Г2
дорожной карты.

| Файл | Что это |
| --- | --- |
| `../../configs/benchmark_sansmic_direct.yaml` | Сценарий для saltcav |
| `run_reference.py` | Тот же сценарий для SANSMIC; пишет `reference_direct.npz` |
| `reference_direct.npz` | Эталон SANSMIC 1.0.7 в СИ (в git, чтобы CI не зависел от SANSMIC) |
| `compare.py` | Таблица метрик и картинка сравнения |
| `../../tests/verification/test_sansmic_benchmark.py` | Допуски сверки в CI |

## Сценарий

Прямоток в цилиндрической затравке R = 5 м на 1000–1100 м, нерастворитель на 1010 м,
закачка пресной воды 50 м³/ч на 1090 м, отбор на 1020 м, 100 суток, нерастворимых 4 %,
камера заполнена насыщенным рассолом.

## Запуск

```bash
python benchmarks/sansmic/compare.py --plot benchmark.png
```

Пересчитать эталон (нужен `pip install sansmic`, лучше в отдельном окружении):

```bash
python benchmarks/sansmic/run_reference.py
```

## Результат (k0 = 3·10⁻⁵ м/с)

| | saltcav | SANSMIC | |
| --- | --- | --- | --- |
| Объём камеры, м³ | 22 679 | 22 689 | 1,000 |
| Радиус 1020–1080 м, м | 9,24 | 9,15 | 1,010 |
| Подошва, м | 1089,5 | 1092,8 | |
| C/C_s на выходе, 10–100 сут | 0,72 | 0,77 | |

Различия, которые остаются:

- **Профиль** у нас почти равномерный (плюм хорошо перемешивает столб), у SANSMIC —
  слабая стратификация и раструб под нерастворителем.
- **Насыщение на выходе** у SANSMIC выше на 0,05. По нашей проверке «вынесено + прирост
  соли в камере» у SANSMIC на ~6 % больше растворённой соли, так что часть разницы —
  в его бухгалтерии или в переводе sg → C.
- **Подошва** у нас выше на 3 м — разные модели насыпи (у нас B = 1,5).
- **Зубцы** на нашей кривой насыщения раз в ~9 суток — погребение слоя целиком:
  вытесненный рассол сразу уходит в отбор. Артефакт учёта, на объём не влияет.

## Ошибка метрического режима SANSMIC 1.0.7

В режиме `Units.M_CM_M3` результаты неверны: выдаваемый объём делится на 5,615
(перевод ft³ → bbl), а прирост радиуса примерно в 3,3 раза больше возможного — баланс
соли не сходится (похоже на смешение футов и метров в скорости отступания стенки).
В родных единицах `FT_IN_BBL` всё согласовано, поэтому `run_reference.py` задаёт
сценарий в футах и баррелях.
