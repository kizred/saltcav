# Изменения

- Значок программы (окно, панель задач, ярлык, отчёт); автор — Sergei Kizre (в «О

## 1.0.0 — 2026-10-24

Первая полная версия: выщелачивание → неопределённость → калибровка → геомеханика →
устойчивость → отчёт.

- **Выщелачивание:** стенка R(z, φ) (осесимметрия или 3D-сектора), закон растворения
  по ориентации стенки, стратификация рассола, струя и плюм от башмака (МТТ),
  нерастворимые и насыпь, прослои и обрушение карнизов, график режима (прямоток,
  противоток, подъём колонн, нерастворитель). Сверка с SANSMIC (объём ±1 %).
- **Неопределённость:** ансамбль Монте-Карло / латинский гиперкуб / Соболь; поля
  скорости растворения и нерастворимых по (z, φ); квантили, сходимость,
  чувствительность; карты вероятностей.
- **Данные и калибровка:** формат CSV скважины (Excel), проверка данных; байесовская
  калибровка (MAP + лаплас, MCMC); синтетический демо-набор и открытый эталон SANSMIC.
- **Геомеханика:** МКЭ P2 с B̄, осесимметрия и 3D (тетраэдры, PARDISO); ползучесть
  BGRa + Мансон–Доусон; прослои как отдельный материал с пределом текучести;
  критерии: дилатансия, напряжения вдоль стенки, конвергенция, отрыв прослоя.
- **Устойчивость по ансамблю:** суррогат (гауссов процесс по признакам формы) с
  уточнением у границы; вероятность потери устойчивости.
- **Окно:** формы параметров из модели, проверка с подсветкой, просмотр по шагам,
  вкладки ансамбля, геомеханики, устойчивости и калибровки, справка (F1), консоль
  Python и скрипты, отчёт в один клик.
- **Командная строка:** check, run, view, ensemble, mechanics, surrogate, data, synth,
  calibrate, report, schema, gui. **Python API** — `saltcav.api`.
- Зависимости 1.0 зафиксированы: `requirements/lock-1.0.txt`.
