# Изменения

## Не выпущено

- **Лицензионное соглашение** (`LICENSE.txt`). Программа бесплатна, в том числе для
  коммерческих расчётов. Изменение, декомпиляция и распространение изменённых копий
  разрешены только с разрешения автора. Результаты расчётов принадлежат пользователю,
  программа предоставляется «как есть». Соглашение показывается при установке, его
  можно открыть в окне («Справка» → «Лицензионное соглашение») или командой
  `saltcav license`.

## 1.1.3 — 2026-10-25

- **Быстрее геомеханика с прослоями.** Сетка сгущается только у кромок карнизов (где
  прослой выходит на стенку), а не вдоль всей границы прослоя; сам прослой в сетке —
  до 3 × наибольший радиус камеры, дальше — соль (`mechanics.layer_extent_factor`,
  пусто — до внешней границы). Тестовая камера в 3D: 29 тыс. → 14 тыс. тетраэдров,
  158 → 68 с; результаты те же (конвергенция до 0,3 %, запас на 95 % стенки до 0,3 %).

## 1.1.2 — 2026-10-25

- «Калибровка» → **«Шаблон данных…»** (и `saltcav data ПАПКА --template`): папка с
  таблицами для Excel под свою скважину — режим и прослои заполнены из текущих
  параметров, остальные таблицы с заголовками, описание столбцов — `ПРОЧТИ.txt`.
- Таблица только с заголовками больше не ошибка — в ней просто нет данных.
- Сборка: установщик загружается и в релиз, созданный вручную на GitHub.

## 1.1.1 — 2026-10-25

- **Исправлено:** на компьютере с многими ядрами калибровка (и ансамбль) в окне падали
  с «BrokenProcessPool» — каждый процесс расчёта запускал BLAS с потоком на каждое ядро,
  и память заканчивалась («файл подкачки слишком мал»). Теперь в процессах BLAS
  однопоточный, процессов не больше, чем позволяет свободная память, а если процесс
  всё же упал — расчёт продолжается в одном процессе.
- Журнал оконной программы (`Документы\saltcav\saltcav-gui.log`) теперь пишут и
  процессы расчёта.
- Автор: Sergei Kizred (была опечатка). В отчёте разделы нумеруются подряд, прослои —
  по-русски.

## 1.1.0 — 2026-10-24

- **Отдельное приложение для Windows:** установщик `saltcav-<версия>-setup.exe` — Python
  и все библиотеки (Qt, VTK, Gmsh, MKL) внутри; ставится без прав администратора;
  ярлыки в «Пуск» и на рабочем столе, по желанию — команда `saltcav` в PATH. Примеры
  при первом запуске копируются в «Документы\saltcav».
- `saltcav selftest` — самопроверка установки (библиотеки, все расчёты на маленьких
  задачах, ≈ минута).
- Сборка установщика в GitHub Actions; по тегу `v*` — релиз с установщиком.

## 1.0.0 — 2026-10-24

Первая полная версия: выщелачивание → неопределённость → калибровка → геомеханика →
устойчивость → отчёт.

- **Выщелачивание:** стенка R(z, φ) (осесимметрия или 3D-сектора), закон растворения
  по ориентации стенки, стратификация рассола, струя и плюм от башмака (МТТ),
  нерастворимые и насыпь, прослои и обрушение карнизов, график режима (прямоток,
  противоток, подъём колонн, нерастворитель). Сверка с SANSMIC (объём ±1 %).
- **Неопределённость:** ансамбль Монте-Карло / латинский гиперкуб / Соболь; поля
  скорости растворения и нерастворимых по (z, φ); квантили, сходимость,
  чувствительность; карты вероятностей.
- **Данные и калибровка:** формат CSV скважины (Excel), проверка данных; байесовская
  калибровка (MAP + лаплас, MCMC); синтетический демо-набор и открытый эталон SANSMIC.
- **Геомеханика:** МКЭ P2 с B̄, осесимметрия и 3D (тетраэдры, PARDISO); ползучесть
  BGRa + Мансон–Доусон; прослои как отдельный материал с пределом текучести;
  критерии: дилатансия, напряжения вдоль стенки, конвергенция, отрыв прослоя.
- **Устойчивость по ансамблю:** суррогат (гауссов процесс по признакам формы) с
  уточнением у границы; вероятность потери устойчивости.
- **Окно:** формы параметров из модели, проверка с подсветкой, просмотр по шагам,
  вкладки ансамбля, геомеханики, устойчивости и калибровки, справка (F1), консоль
  Python и скрипты, отчёт в один клик.
- **Командная строка:** check, run, view, ensemble, mechanics, surrogate, data, synth,
  calibrate, report, schema, gui. **Python API** — `saltcav.api`.
- Зависимости 1.0 зафиксированы: `requirements/lock-1.0.txt`.
